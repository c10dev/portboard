When a session ends
Nothing is stopped when a session ends. Leftover servers show up in the Services tab's cleanup banner.
  • Off (default)Nothing is stopped when a session ends. Leftover servers show up in the Services tab's cleanup banner.
  • Scratchpad and temporary units onlyStops only the servers running in that session's scratchpad and the temporary units Portboard started (pb-dev-, pb-sd-). Servers in worktrees are left alone.
  • All of that session's serversStops every server that session started (except pinned ports and services that aren't cleanup candidates).
