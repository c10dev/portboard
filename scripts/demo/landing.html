Portboard

A dashboard of every TCP port listening on a Linux server, the devices on your Tailscale tailnet, and your dev worktrees. Open any service from your laptop or phone with one click, and let Claude Code pick ports and start dev servers through it instead of guessing.

Try the demo Install GitHub
  • ServicesEvery listening port with its owner: process, project, systemd unit or docker container, bind scope, and who is connected now.
  • One click to openPublish a loopback-only HTTP port to your tailnet with tailscale serve, and unpublish it again.
  • DevicesTailnet devices with their load and the ports they use; optionally a Proxmox host and a desktop's Windows side.
  • Dev servers and worktreesStart and stop dev servers, reserve ports per project, and find worktrees that are safe to clean up.
  • AlertsDown alerts for watched ports and devices, new-device notices and digests over ntfy or a webhook.
  • For AI agentsA local MCP server, a Claude Code plugin, and an optional read-only remote MCP connector.

Install

Linux with ss, Node.js ≥ 22.18 and Tailscale. No dependencies to install.

git clone https://github.com/c10dev/portboard.git ~/projects/portboard
cd ~/projects/portboard
npm start    # http://127.0.0.1:8790

Then publish it to your tailnet and read the security model: Quick start · Security · Setup.
