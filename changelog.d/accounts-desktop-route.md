### Added
- Accounts: a desktop route for the accounts proxy. With `accounts.proxy.desktop.enabled`, the proxy listener also takes HTTP `CONNECT`, so a Claude Code session whose settings set `HTTPS_PROXY` (with the proxy key) and `NODE_EXTRA_CA_CERTS` (a certificate Portboard makes, valid for `api.anthropic.com` only) reaches it, including a session of the desktop app's Code tab, which forces `ANTHROPIC_BASE_URL`. Portboard decrypts `api.anthropic.com` only: a `/v1/messages` request for a GPT lane model goes to the lane, and every other request is relayed to Anthropic unchanged with the session's own login. Every other host is a plain tunnel. Portboard edits no settings file and installs no certificate. See docs/accounts.md#desktop-route.
