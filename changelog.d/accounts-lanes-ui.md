### Added
- Accounts: Settings › Accounts › Proxy has switches for the GPT lane and the desktop route, an editor for the model mapping, a **Copy desktop settings** button and a line that counts what the two lanes did. A change applies at once, without editing `portboard.json` or restarting Portboard. The values are kept in `accounts-lanes.json` in the config folder (mode 0600, `PORTBOARD_ACCOUNTS_LANES`), which overrides `accounts.proxy.gpt` and `accounts.proxy.desktop` for each key it holds. New route `POST /api/accounts/proxy/lanes` (owner only); `POST /api/accounts/proxy/key` also answers `certFile`; the proxy report has `lanes` and `activity`.
