### Added
- Accounts: the account pool proxy now also serves Codex. Start Codex with the new "Copy Codex command" button (Settings › Accounts › Proxy; the old button is now "Copy Claude command"): Codex sends `POST /codex/responses` to the proxy, which sends it to `chatgpt.com` with the token and account id of one added ChatGPT/Codex account, and to the next Codex account on a `429` or `402`. Claude and Codex accounts rest and switch apart, `proxy.current` is now `{claude, codex}`, and each proxy event has its `provider`. WebSocket is not proxied. The ChatGPT side is not verified with the real service yet. See docs/accounts.md#proxy.
