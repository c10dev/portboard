### Changed
- One TTL cache helper (`src/core/cache.ts`: `ttlCache`, `keyedCache`, `TtlMap`) replaces the cache code repeated across the Proxmox, compute-pool, site, Proxmox-trends, host-key, owner, whois and suggestion lookups and the remote server. The caches that never dropped anything (PTR names per LAN address, git and title lookups per path, host keys, site per port) now keep a bounded number of entries (#4).
- The alert checker and the self-watch run on the shared job scheduler instead of their own timers, so they also show in `/api/health?detail` → `runtime.jobs`. Their cadence is the same: the checker every 30 s from start, the self-watch every minute with its first look 20 s after start (#4).
- One shared `/proc` process reader (`src/core/proc.ts`) for the memory sampler and the worktree scan, and `src/core/memory.ts` split into modules under `src/core/memory/` (same exports). No behaviour change (#4).
