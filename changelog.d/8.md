### Added
- Remote connector (claude.ai / ChatGPT): `list_worktrees`, read-only and redacted. Repository and branch names, state (merged, unmerged, locked, missing), PR number and state, changed yes/no, size, whether a process runs inside, removable and the reasons to keep it, and the totals. Never paths, commit messages, remote URLs or pids. It reads the last scan the dashboard saved (new `worktrees-state.json` in the state dir) and never scans, so there is no `refresh` remotely (#8).
- Remote connector: `list_dev_servers`, read-only and redacted. Each dev server Portboard started, by `<repo>@<branch>`, with its state, port and start time, plus which worktrees could be started and with which script names. Never paths, unit names or script commands (#8).
- Remote connector: `memory_usage`, read-only and redacted, from the dashboard's last sample in `memory-state.json`. It shows memory, swap, PSI, the pressure state and its thresholds, the groups and totals, and the sizes per session, service and container. Session titles and projects, MCP server and process names and the suggestion texts appear only when `remote.json` sets `showProcesses` (#8).
- The stdio MCP server's `list_worktrees` uses the dashboard's saved scan while it is less than an hour old instead of starting its own first scan (#8).
