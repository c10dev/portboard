### Changed
- Ports swapped (2026-10-18): the public read-only remote MCP is now on **Funnel 443** (`https://devbox.example.ts.net/mcp`) and the dashboard on **`tailscale serve` 8443, tailnet only** (`https://devbox.example.ts.net:8443`). claude.ai never reached the connector on 8443. The menu bar default URL, `mac-setup.sh`, the deploy smoke check, alert links (now taken from `tailscale serve status`, or `PORTBOARD_DASHBOARD_URL`) and the docs follow. Reinstall the Mac menu bar plugin or set `PORTBOARD_URL` to the :8443 address.
- Remote connector consent page: `Referrer-Policy: same-origin` (header and the page's `<meta name="referrer">`) instead of `no-referrer`. Under `no-referrer` a browser sends `Origin: null` with the approval form, which the Origin check refused ("origin not allowed"), so no browser could approve a connection. The referrer still never leaves the site.
