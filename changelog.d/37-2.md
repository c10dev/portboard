### Changed
- The rest of the devbox literals outside `src/` (#37). The web app manifest says "Listening ports on this server", the 기기 tab's subnet-router hint falls back to "이 서버" when there is no self card, and the Claude Code plugin's `dev-servers-and-ports` skill says "this server".
- `scripts/mac-setup.sh` and `scripts/mac-menubar-setup.sh` take the server's SSH target as an argument (`bash /tmp/mac-setup.sh dev@devbox.example.ts.net`), or from `PORTBOARD_REMOTE`, instead of defaulting to devbox. Without one they stop with a usage line; the menu bar installer needs it only when it isn't run from a checkout. `mac-setup.sh` registers the launcher as `projects/portboard/bin/portboard-mcp` relative to the SSH user's home instead of `/home/dev/…` (same file; re-running it rewrites the Claude Desktop entry) and prints the dashboard address from the target's host. The commands in docs/mcp.md, docs/setup.md and docs/menubar/ pass the target. See [docs/config.md](docs/config.md#outside-src).
