### Fixed
- Flaky tests on devbox ("session-end.ts as a CLI", and "autoStop per mode against real processes"), one of which blocked a deploy. The SessionEnd hook itself was fine. The live Portboard probes every new loopback listener with `GET /` for its `<title>`, and the tests' fake Portboard/ntfy servers took that probe for the hook's request: an empty body for `JSON.parse`, or an extra entry in what they recorded. The fakes now record only the requests under test. The real-process auto-stop test kept its scratchpads under one `/tmp/claude-<uid>/-portboard-test` shared by every concurrent `npm test` on the machine, and each run's cleanup deleted the others' directories mid-test (`cwd-gone`, and a hang from leaked dummy servers). The root is now per process, and each dummy server is tracked as soon as it starts.
