### Changed
- The remote MCP server reads snapshot, devices and usage from the dashboard over loopback (`GET /api/ports`, `/api/devices`, `/api/usage` on `127.0.0.1:PORTBOARD_PORT`) instead of running `ss`, `docker ps`, `tailscale status`, `serve status` and the port probes a second time. Redaction is unchanged and applies to the same core objects; the dashboard's extra usage fields (history, 새 기기) are never copied (#5).
- When the dashboard doesn't answer (refused, or no connection within 1.5 s), the remote server computes those reads itself and tries the dashboard again after 10 s, with one log line when it goes away and one when it is back. `list_devices` now shows the LAN clients in the network tree as the 기기 tab does, aliased like everywhere else (#5).
