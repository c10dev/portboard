### Added
- Accounts: a GPT lane in the account pool proxy. With `accounts.proxy.gpt` on and model names listed, a Claude Code request (`POST /v1/messages`) for a listed model, or a `codex/<id>` model, is converted to a Responses request and sent to `chatgpt.com` with an added ChatGPT/Codex account (with the Codex switching rules). The answer is converted back, so `claude --model codex/<id>` runs on a GPT model with tool calls. Every other request passes through as before. This is not an official way to use a ChatGPT subscription and an account may be limited. See docs/accounts.md#gpt-lane.
