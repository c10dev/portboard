### Added
- **Remote `machine_status`**: the remote MCP server (claude.ai connector) now answers `machine_status`, redacted: per machine its kind, online, data age, load, Claude Code session counts, checkouts as `repo@branch` (changed yes/no, ahead/behind), port counts and capabilities. It reads `machines-state.json`, which the dashboard server writes each time it reads its agents; it never asks an agent itself (`fresh` is local only). Session ids, paths, git remotes, tailnet ids and launch notes are never sent; a session's project and `repo@branch` only with `showProcesses` ([docs/remote-mcp/README.md](docs/remote-mcp/README.md#tools-allowlist), [SECURITY-REVIEW.md](docs/remote-mcp/SECURITY-REVIEW.md#widening-machine_status)). `find_worktree` and `where_to_run` stay local.
