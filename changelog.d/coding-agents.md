### Added
- Four MCP tools on the local stdio server hand a task to another coding agent on the same host: `start_coding_agent` runs the Codex CLI (or the Gemini CLI) non-interactively in a known worktree, `list_coding_agents` and `coding_agent_output` show the state, progress and final answer, and `stop_coding_agent` stops a run. The sandbox is read-only unless the caller asks for `workspace-write`, which works only for Codex and is refused in a main checkout. Gemini runs read-only only, and its read-only is the CLI's approval mode, not an OS sandbox. A run is a transient systemd unit (`pb-agent-<id>`) or, without systemd, a detached process, with a runtime limit. The prompt goes to the CLI on stdin and is never logged. No HTTP route and no remote tool. See docs/agents.md and docs/security.md.
