### Added
- **설정 tab** (`settings.html`, fourth header tab on every page and in ⌘K): every setting and setup step in one place. Sections: 시작하기 (the setup checklist), 원격 커넥터, 쓰기 허용 기기, 알림 (channel status and 요약 알림), Claude 세션 (session-end auto-stop), 비밀값 (status, expiry and rotation runbook of each token and key, never a value) and 정보 (version, deployed and running commit, addresses, docs). Each section is its own feature script; the new modules `write-devices` and `settings` come last in the registry. Read-only viewers see every section with the write controls greyed out and the reason ([docs/settings](docs/settings/README.md)).
- **승인 코드 만들기 on the dashboard**: `POST /api/remote/approval-code` makes the same one-time code as `node src/remote.ts approve` (10 min, single use; a new one replaces the pending one). The page shows it once, large, with a countdown, 복사 and 다시 만들기, and says when it was used. An owner write through the router's guard, audited without the code; no MCP tool, local or remote, makes one. `GET /api/remote/clients` adds `connectorUrl` (the URL to paste) and `approvalExpiresAt`.
- **쓰기 허용 기기 from the dashboard**: `GET`/`POST /api/settings/write-devices` list the owner's tailnet devices and save the checked ones to `access.json` (0600, atomic, other keys kept). A list that leaves out the device you are using is refused (409), so a save can't lock you out; loopback stays the owner whatever the list says.
- `GET /api/settings`: version, `deployed.json`, the running commit, the dashboard/connector/direct addresses and the secrets' status for the tab.
