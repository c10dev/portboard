### Added
- **Public demo and landing page** ([docs/demo.md](docs/demo.md)): `npm run demo` builds a static, read-only copy of the dashboard on example data into `demo/`, with a landing page (the pitch, screenshots, links to the demo, install and GitHub), for https://c10dev.github.io/portboard/. Every page is the real one from `public/`, expanded as the server serves it; a small shim answers its `GET /api/…` calls from JSON files (`scripts/demo/data/api/`, plus groups, the network map, history, uptime and each service page computed with the server's own functions), keeps timestamps current, answers every write with "read-only demo" without sending anything, and shows a "Demo with example data" banner in English or Korean (#13)
- The demo build refuses to run unless the site config is `portboard.example.json` and the data is the example host's, and scans its output with `scripts/public-scan.mjs` (new `--allow-images` option) before replacing `demo/` (#13)
- `.github/workflows/demo.yml` deploys the demo to GitHub Pages on every push to `main` and on demand, actions pinned by commit SHA; it publishes once Pages is set to "GitHub Actions" in the repository settings (#13)
